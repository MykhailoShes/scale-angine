# Scale Engine — Інструкція для клієнта

> Версія для касира / адміністратора магазину. Якщо потрібен технічний опис інтеграції — див. `README.md`.

## 1. Установлення

1. **Якщо у вас вже стояла версія "Scale Angine"** — деінсталюйте її через Панель керування → Програми (Windows) або перетягніть у корзину з Applications (macOS). Ваші налаштування збережуться і автоматично підхопляться новою версією при першому запуску.
2. Запустіть інсталятор **`Scale-Engine-Setup-1.1.0.exe`** (Windows) або відкрийте **`Scale-Engine-1.1.0.dmg`** (macOS).
3. Слідуйте звичайним крокам інсталятора. На Windows можна обрати куди встановлювати; на робочий стіл і у меню Пуск автоматично додасться ярлик **Scale Engine**.
4. Перший запуск відбувається з порожньою конфігурацією — або зі збереженими налаштуваннями попередньої версії, якщо ви оновлюєтесь.

## 2. Налаштування з'єднання

Після запуску ви побачите вікно з кількома секціями:

### SFTP Connection
- **SFTP URL** — адреса вашого SFTP-сервера у форматі `sftp://USERNAME@HOST:22`. Пароль можна або вписати після username через двокрапку (`sftp://USER:PASSWORD@HOST:22`), або помістити в окреме поле нижче — як вам зручніше.
- **SFTP Password** — окреме поле для пароля (рекомендовано). Він шифрується і зберігається у захищеному сховищі операційної системи. Натисніть 👁 щоб тимчасово побачити введене.

### SFTP Folder
- **Folder Name** — назва підпапки на SFTP, яка зафіксована за вашими вагами (наприклад, `DIsaH6` або `vUqt32`). Цю назву видає бекенд при створенні нової ваги.

### Local directories
- **Import directory (received)** — локальна папка, в яку Mettler Toledo очікує отримувати XML файли продуктів. Сюди Scale Engine буде **записувати**.
- **Export directory (sent from)** — локальна папка, в яку Mettler Toledo записує XML чеки після зважування. Звідси Scale Engine буде **читати**.

Для обох локальних папок натисніть **📁** щоб обрати папку через стандартний діалог.

### Mode
- **Inventory mode** — галочка для інвентаризації. Коли вона увімкнена, чеки йдуть на SFTP у `/upload/inventory_import` і **не рахуються як продажі**. Саму вагу в режим інвентаризації потрібно перемкнути вручну. Після зміни натисніть **Save** (перезапуск не потрібен). Не забудьте вимкнути галочку після інвентаризації.

## 3. Кнопки

| Кнопка   | Що робить                                                                 |
|----------|---------------------------------------------------------------------------|
| **Save** | Зберігає введені значення без запуску роботи                              |
| **Start**| Зберігає, відкриває з'єднання з SFTP і починає слухати папки              |
| **Stop** | Зупиняє слухачі і закриває SFTP-з'єднання                                 |

Зеленa крапка зверху означає **Running**, сіра — **Idle**, червона — **Error** (текст помилки буде поруч).

## 4. Activity log

Нижня панель показує всі події у реальному часі:
- зелене ✓ — файл успішно переданий
- жовте ⚠ — попередження (наприклад, не вдалось перенести у processed)
- червоне — помилка

Цей лог не зберігається між запусками — щоб подивитись історію, відкрийте папки `processed/` (локальну в `<Export>/processed` та віддалену `/upload/<FolderName>/export/processed`).

## 5. Що відбувається насправді

**Чек з ваг → бекенд:** як тільки Mettler Toledo кладе новий `.xml` у вашу Export-папку, Scale Engine завантажує його на SFTP у `/upload/import`, де його забирає мідлвар. Локальна копія переноситься у `<Export>/processed`.

**Продукт з бекенду → ваги:** мідлвар (через POS App) кладе новий `.xml` у `/upload/<FolderName>/export/` на SFTP. Scale Engine його скачує у вашу Import-папку (де Mettler Toledo одразу його підхоплює) і переносить на SFTP у `/upload/<FolderName>/export/processed`.

Затримка між появою файлу і його передачею — приблизно 3 секунди (поллінг кожні 2.5с + перевірка стабільності файлу 1.5с).

## 6. Якщо щось не так

| Симптом                                              | Що зробити                                                                          |
|------------------------------------------------------|-------------------------------------------------------------------------------------|
| Червона крапка, `All configured authentication...`   | Перевірте пароль; в логу буде довжина пароля яка дійшла до клієнта                  |
| Червона крапка, `Missing config: ...`                | Не заповнене якесь поле — заповніть і натисніть Start ще раз                        |
| Зелена крапка, але файли не передаються              | Перевірте що Folder Name співпадає з налаштуванням вашої ваги у бекенді             |
| `SFTP connection ended → will reconnect`             | Це нормально, програма сама перепідключається з затримкою 1-30с                     |
| Запитує продовжити при закритті                      | Якщо натиснути Cancel — вікно залишиться відкритим; це захист від випадкового виходу |

Якщо потрібна допомога, надішліть скріншот activity-log + версію програми (видно у заголовку вікна) на адресу підтримки.
